🚀 OPCIÓN 1: PROBAR EN 5 MINUTOS
═══════════════════════════════════════════════════════════════════════════════

1. Abre http://localhost:3000

2. Haz clic en el menú ☰ (arriba a la izquierda)

3. Selecciona "Idiomas"

4. Elige un idioma (ej: English)

5. ✅ Verifica que TODO cambió de idioma

6. Recarga la página (F5)

7. ✅ El idioma debe haber persistido

¡Listo! El sistema funciona. 🎉


💻 OPCIÓN 2: USAR EN TU CÓDIGO (10 minutos)
═══════════════════════════════════════════════════════════════════════════════

Paso 1: Abre un componente que quieras traducir

Paso 2: Añade esta importación al inicio:

    import { useLanguage } from '../context/useLanguage';

Paso 3: Dentro de tu función componente, añade:

    const { t } = useLanguage();

Paso 4: Reemplaza los textos:

    // Antes:
    <h1>Bienvenido</h1>
    
    // Después:
    <h1>{t('dashboard.welcome')}</h1>

¡Listo! Ahora ese texto se traduce automáticamente. 🎊
