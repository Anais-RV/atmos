🚀 CÓMO USAR
═══════════════════════════════════════════════════════════════════════════════

En Componentes:

  import { useLanguage } from '../context/useLanguage';

  function MiComponente() {
    const { t, language, setLanguage } = useLanguage();
    
    return (
      <div>
        <h1>{t('settings.title')}</h1>
        <p>Idioma actual: {language}</p>
        <button onClick={() => setLanguage('en')}>English</button>
      </div>
    );
  }

Acceso a Traducciones:

  const { t } = useLanguage();
  
  t('common.loading')           // "Cargando..."
  t('hamburger.userMenu')       // "Menú de usuario"
  t('settings.language')        // "Idioma"
  t('auth.login')              // "Iniciar sesión"
  t('weather.temperature')      // "Temperatura"

Cambiar Idioma:

  const { setLanguage } = useLanguage();
  
  setLanguage('es');     // Español
  setLanguage('en');     // Inglés
  setLanguage('pt');     // Portugués
  setLanguage('pt_BR');  // Portugués Brasileño
  setLanguage('ru');     // Ruso


🧪 PRUEBAS
═══════════════════════════════════════════════════════════════════════════════

Prueba Rápida (Sin Autenticación):
  1. Abre http://localhost:3000
  2. Haz clic en ☰ (HamburgerMenu)
  3. Selecciona "Idiomas"
  4. Elige un idioma
  5. Verifica que todo cambia de idioma
  6. Recarga la página (F5)
  7. ✅ El idioma debe persistir

Prueba con Autenticación:
  1. Inicia sesión
  2. Ve a /settings
  3. Cambia el idioma
  4. Haz clic en "Guardar cambios"
  5. Verifica mensaje de éxito
  6. Recarga la página
  7. ✅ El idioma debe estar sincronizado

Componente de Debug:
  • Muestra idioma actual
  • Botones para cambiar
  • Ejemplos de traducciones
  • Información de localStorage
